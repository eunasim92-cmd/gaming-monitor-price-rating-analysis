# 게이밍 모니터 가격과 평점의 관계 분석

## 프로젝트 개요
영업관리 업무 당시 신사업으로 게이밍 모니터 판매를 준비하는 과정에서, 국내에 처음 소개되는 브랜드의 제품이 이미 인지도가 높은 브랜드와 유사한 가격대로 책정된 것을 확인했습니다.
이에 가격이 높을수록 소비자 만족도가 낮아질 것이라는 가설을 세우고, 공개 데이터를 활용해 가격과 소비자 평점의 관계를 확인했습니다.

>Research Question
>게이밍 모니터의 가격이 높을수록 소비자 평점이 낮아지는가?
>가격 외에 평점에 영향을 미치는 제품 특성은 무엇인가?

※ 본 프로젝트는 실제 판매 데이터가 아닌 공개 데이터를 활용한 탐색적 분석으로, 국내 소비자의 실제 구매행동을 직접 예측하기보다 가격과 제품 특성 간의 관계를 탐색하는 데 목적이 있습니다.

## 데이터
- 출처: Kaggle 공개 데이터셋 (Amazon 게이밍 모니터 상품 정보)
- 활용 이유: 실제 판매 채널인 Amazon 데이터를 직접 수집할 수 없는 상황이라,
  동일 시장(Amazon) 조건의 공개 데이터로 대체 분석 진행
- 파일: `extracted_product_info_amazon.csv`
- 원본 규모: 947개 → 전처리 및 게이밍 모니터 필터링 후 542개 사용

## 분석 과정
1. **데이터 수집**: Kaggle에서 Amazon 게이밍 모니터 상품 정보(제목, 브랜드, 해상도, 평점, 가격) 확보
2. **전처리**:
   - 데이터 타입 변환 (Rating/Price → float)
   - 결측치 처리 (Rating 결측 3.7% 제거)
   - 이상치 처리 (Price 상위 1% 및 20달러 미만 제거)
   - Title 텍스트에서 정규식으로 주사율(Refresh Rate) 추출 및 수동 보정
3. **EDA**: 가격 구간별/브랜드별/해상도별/주사율별 평점 분포를 산점도·박스플롯으로 탐색
4. **회귀분석**: 단순선형회귀 + OLS로 가격-평점 단일 관계 검증
5. **랜덤포레스트**: 브랜드·해상도·주사율·가격을 동시에 고려한 변수 중요도 분석, 5-Fold 교차검증으로 결과 안정성 검증

## 핵심 결과

**단순선형회귀 / OLS**
- Price_category 계수: -0.0073 (가격 한 단계 상승 시 평점 평균 0.007점 하락)
- p-value = 0.044 (통계적으로 유의하나 효과는 미미)
- R² = 0.007 (설명력 거의 없음) → 가격 단독으로는 평점을 설명하기 어려움

**랜덤포레스트 Feature Importance**

| 요인 | Importance |
|---|---|
| Brand | 0.488 |
| Resolution | 0.203 |
| Refresh Rate | 0.167 |
| Price | 0.141 |

- 모델 R² = 0.684
- 5-Fold 교차검증(shuffle=True) 결과 R² 평균 0.662, 표준편차 0.090으로 특정 데이터 분할에서 우연히 높게 나온 값이 아님을 확인
  - 참고: shuffle 없이 검증했을 때는 표준편차 0.318로 크게 흔들렸는데, 이는 원본 데이터가 특정 순서로 정렬돼 있어 폴드별로 브랜드/가격대 분포가 불균형했기 때문으로 확인됨
- 다만 브랜드 더미변수가 20개 이상으로 많아, 이 R²는 순수 예측력이라기보다 개별 브랜드의 평균 평점을 학습한 결과에 가까움. 따라서 "모델 설명력이 높다"보다는 **"브랜드가 평점을 좌우하는 가장 지배적인 요인"** 이라는 근거로 해석하는 것이 더 타당함

**결론**
- 가격과 평점은 유의미하게 관련은 있지만 영향력은 매우 미미함 → "비싸다고 꼭 만족도가 높은 건 아니다"
- 브랜드가 평점에 가장 큰 영향을 미침 (브랜드 인지도·신뢰도·AS 등 외부 요인 반영 추정)
- 해상도·주사율도 일정 영향이 있으나, 고사양이 반드시 높은 평점을 보장하지는 않음
- 종합하면, 가격 정책만으로 소비자 만족도를 끌어올리기는 어렵고 브랜드 신뢰도 및 제품 스펙 관리가 더 중요한 변수로 확인됨

## 사용 기술
Python, Pandas, Plotly, Matplotlib, scikit-learn (LinearRegression, RandomForestRegressor), statsmodels

## 한계
- 표본 규모(542개) 대비 브랜드 원핫인코딩 변수가 20개 이상으로 많아, 랜덤포레스트 R²는 예측력이라기보다 "브랜드별 평균 평점을 학습한 결과"에 가까움
- 교차검증 결과 폴드 간 R² 변동(0.537~0.785)이 있어 완전히 안정적인 수치는 아님
- 미국 Amazon 시장 데이터로, 국내 소비자 반응과는 차이가 있을 수 있음
